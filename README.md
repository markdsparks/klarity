# Klarity

An evidence-tiered food scanner — a calibrated alternative to Yuka. Two separate readings for every
food (additives and nutrition), three verdict states (everyday · sometimes · contested), and the
evidence behind every verdict one tap away.

Native iOS (Swift / SwiftUI, iOS 26+). See `CLAUDE.md` for how the project is built and run.

```bash
npm run native:gen    # generate the Xcode project (needs xcodegen and a .env with API keys)
npm run test:swift    # engine tests
```
